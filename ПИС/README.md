# Полный комплект лабораторных работ (ЛР1–ЛР9)

Этот репозиторий содержит все лабораторные работы по дисциплине “Web‑программирование”, каждая из которых находится в отдельной папке.  
Также в репозитории присутствует единый Django‑проект, объединяющий лабораторные работы №2–6.

## Лабораторная работа №1 — Python

Папка **Lab1** содержит:

- `helloworld.py` — вывод строки  
- `groupmates.py` — список студентов  
- `filter_students.py` — фильтрация по среднему баллу  

Запуск:

```bash
python helloworld.py
python groupmates.py
python filter_students.py
```

## Лабораторные работы №2–6 — Django‑проект
Папки **Lab2–Lab6** содержат поэтапные версии проекта, выполненные по методичке.

- Папка Весь Django‑проект содержит полностью собранный рабочий сайт, включающий:
- шаблоны и статику (ЛР2)
- модель Post и админку (ЛР3)
- страницу отдельного поста (ЛР4)
- форму создания поста (ЛР5)
- регистрацию и авторизацию пользователей (ЛР6)

Запуск Django‑проекта
```bash
cd "Весь Django-проект"
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
Основные адреса

**Главная страница:**
http://127.0.0.1:8000/ (127.0.0.1 in Bing)

**Создание поста:**
http://127.0.0.1:8000/post/new/ (127.0.0.1 in Bing)

**Страница поста:**
http://127.0.0.1:8000/post/ (127.0.0.1 in Bing)<id>/

**Вход:**
http://127.0.0.1:8000/accounts/login/ (127.0.0.1 in Bing)

**Регистрация:**
http://127.0.0.1:8000/accounts/register/ (127.0.0.1 in Bing)

**Админка:**
http://127.0.0.1:8000/admin/ (127.0.0.1 in Bing)

## Описание проекта
Репозиторий объединяет все лабораторные работы в единую структуру:

* ЛР1 — Python‑скрипты
* ЛР2–ЛР6 — Django‑сайт (блог + авторизация)
* ЛР7–ЛР9 — JavaScript и jQuery мини‑проекты

Каждая лабораторная находится в отдельной папке, а также собрана в общий рабочий проект.
