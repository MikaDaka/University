# Лабораторная работа №9

Эффект параллакса для главной страницы блога.

## Что реализовано

- параллакс‑фон с использованием CSS (`background-attachment: fixed`)
- усиленный параллакс‑эффект через JavaScript (динамическое смещение фона)
- плавная работа на всех современных браузерах
- структура проекта, готовая для GitHub

## Файлы

- `index.html` — главная страница
- `style.css` — оформление и параллакс‑фон
- `parallax.js` — динамическое смещение фона

## Как запустить

Открыть файл `index.html` в браузере.

## Требования

Браузер с поддержкой JavaScript.
